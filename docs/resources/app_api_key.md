# onesignal_app_api_key (Resource)

An App API key. OneSignal returns a key's value only when it is created or rotated, so `value` is captured then and kept in state; an imported key has none. Changing `rotate_when_changed` rotates the key in place: same ID, new value, the old one revoked at once. Destroying it revokes it.

## Example Usage

```terraform
resource "onesignal_app_api_key" "server" {
  app_id = onesignal_app.example.id
  name   = "server"

  # Only these addresses may use the key. Leave it empty to allow any.
  ip_allowlist = ["192.0.2.10/32", "2001:db8::10/128"]

  # Changing any value here rotates the key in place.
  rotate_when_changed = {
    rotation = "2026-11"
  }
}

output "server_api_key" {
  value     = onesignal_app_api_key.server.value
  sensitive = true
}
```

## Schema

### Required

- `app_id` (String) The app the key belongs to.
- `name` (String) The key's name.

### Optional

- `ip_allowlist` (Set of String) The CIDR ranges, IPv4 or IPv6, the key may be used from; a single address is a `/32` or `/128`. Unset or empty, it may be used from anywhere.
- `rotate_when_changed` (Map of String) Arbitrary values; any change rotates the key.

### Read-Only

- `created_at` (String) When the key was created.
- `id` (String) The key's ID, OneSignal's `token_id`. It is not the key.
- `value` (String, Sensitive) The key itself, from its creation or last rotation.
