# onesignal_segment (Resource)

A segment of an app, defined by filters. OneSignal's API cannot manage segments built on message-event or custom-event filters, and refuses to create segments on some plans, the Free plan among them (HTTP 403). An imported segment is not read until its first apply, which needs `api_key` and writes the configuration over it.

## Example Usage

```terraform
resource "onesignal_segment" "engaged" {
  app_id      = onesignal_app.example.id
  api_key     = onesignal_app_api_key.server.value
  name        = "Engaged"
  description = "Frequent users in the US, or anyone on the pro plan"

  # Adjacent filters are joined by AND; an OR operator separates groups.
  filters = [
    { field = "session_count", relation = ">", value = "5" },
    { field = "country", relation = "=", value = "US" },
    { operator = "OR" },
    { field = "tag", key = "plan", relation = "=", value = "pro" },
  ]
}
```

## Schema

### Required

- `api_key` (String, Sensitive) An App API key of the app, normally an `onesignal_app_api_key`'s `value`. OneSignal refuses the Organization API key for segments and templates.
- `app_id` (String) The app the segment belongs to.
- `filters` (Attributes List) The filters, in order: each entry is a filter, or `{ operator = "OR" }`. Adjacent filters are joined by AND, which binds tighter than OR, so the list is an OR of AND groups. Every operand is a string, as OneSignal stores it. (see [below for nested schema](#nestedatt--filters))
- `name` (String) The segment's name, unique within the app.

### Optional

- `description` (String) The segment's description.

### Read-Only

- `id` (String) The segment's ID.
- `source` (String) Where the segment came from: `custom`, `default` or `quickstart`.

### Nested Schema for `filters`

Optional:

- `field` (String) What the filter tests: `tag`, `last_session`, `first_session`, `session_count`, `session_time`, `language`, `app_version`, `location` or `country`.
- `hours_ago` (String) Hours, as a string, for `last_session` and `first_session`.
- `key` (String) The tag's key, for `tag` filters.
- `lat` (String) Latitude, for `location`.
- `long` (String) Longitude, for `location`.
- `operator` (String) `OR`, alone in its entry, between two AND groups.
- `radius` (String) Metres, for `location`.
- `relation` (String) The comparison, such as `=`, `!=`, `>`, `<`, `exists`, `not_exists`, `in_array`, `time_elapsed_gt`.
- `value` (String) The value compared, as a string.
